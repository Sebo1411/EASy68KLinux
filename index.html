EASy68K Linux Native Repository

Official automatic update repository for Sebo1411/EASy68KLinux.

1. Debian / Ubuntu / Kubuntu / Linux Mint (APT)

curl -fsSL https://sebo1411.github.io/EASy68KLinux/setup-apt.sh | sudo bash

2. Fedora / RHEL / openSUSE (DNF / RPM)

curl -fsSL https://sebo1411.github.io/EASy68KLinux/setup-rpm.sh | sudo bash

3. AppImage Delta Updates (zsync) & Direct Downloads

All .AppImage builds embed AppImageUpdate delta-update metadata and include an integrated GUI Auto-Updater under Help → Check for Updates....
